1. การเข้าร่วมการฝึกและความเสี่ยง

Brazilian Jiu-Jitsu (BJJ) เป็นกีฬาที่มีการสัมผัสร่างกาย การจับ ทุ่ม กด ล็อก และรัด ซึ่งอาจทำให้เกิดอุบัติเหตุ หรือการบาดเจ็บได้ ผู้สมัครรับทราบความเสี่ยงดังกล่าว และเข้าร่วมการฝึกด้วยความสมัครใจ โดยตกลงปฏิบัติตาม คำแนะนำของโค้ชและกฎความปลอดภัยของยิม

การรับทราบความเสี่ยงนี้ไม่เป็นการตัดสิทธิของสมาชิก หรือยกเว้นความรับผิดในกรณีที่กฎหมายไม่อนุญาต

2. สุขภาพและความพร้อมในการฝึก

ผู้สมัครยืนยันว่าข้อมูลสุขภาพ โรคประจำตัว การแพ้ยา/อาหาร และข้อจำกัดทางร่างกายที่แจ้งแก่ยิมเป็นข้อมูลที่ถูกต้อง ตามความเข้าใจของตน

หากมีอาการบาดเจ็บ เจ็บป่วย หรือภาวะที่อาจกระทบต่อความปลอดภัย สมาชิกควรแจ้งโค้ชก่อนฝึกและหยุดฝึกทันทีเมื่อรู้สึกไม่ปลอดภัย หากไม่แน่ใจในความพร้อมของร่างกาย ควรปรึกษาแพทย์ก่อนเข้าร่วมการฝึก

3. ความปลอดภัยและกฎการฝึก

สมาชิกตกลงปฏิบัติตามคำแนะนำของโค้ช ใช้เทคนิคอย่างเหมาะสม กับระดับของตน ไม่จงใจทำให้ผู้อื่นได้รับบาดเจ็บ และต้องหยุดหรือปล่อยเทคนิคทันทีเมื่อคู่ฝึก Tap หรือส่งสัญญาณยอมแพ้

ยิมสงวนสิทธิ์ให้สมาชิกหยุดพักหรือหยุดการฝึก หากโค้ชเห็นว่าการฝึกต่ออาจเป็นอันตรายต่อตนเองหรือผู้อื่น

4. สุขอนามัย

สมาชิกต้องรักษาความสะอาดของร่างกายและชุดฝึก ตัดเล็บให้เหมาะสม และงดเข้าร่วมคลาสหากมีโรคติดต่อทางผิวหนัง แผลเปิด หรือภาวะที่อาจแพร่เชื้อให้ผู้อื่น

5. แพ็กเกจและสิทธิสมาชิก

สิทธิการเข้าเรียนเป็นไปตามแพ็กเกจที่สมาชิกเลือก เช่น Drop-in, Class Pass, Monthly, Private Class หรือแพ็กเกจอื่นของยิม

วันเริ่มต้น วันหมดอายุ จำนวนครั้ง และเงื่อนไขการใช้งาน เป็นไปตามข้อมูลที่แสดงในระบบหรือเงื่อนไขของแพ็กเกจ ณ เวลาที่สมัคร

สำหรับ Class Pass ระบบจะหักสิทธิเมื่อมีการเช็กอินเข้าเรียน และเมื่อใช้สิทธิครบหรือแพ็กเกจหมดอายุ สมาชิกต้องต่ออายุก่อนใช้บริการต่อ

6. การจองและการเข้าเรียน

สมาชิกต้องจองหรือเช็กอินคลาสตามระบบที่ยิมกำหนด บางคลาสอาจจำกัดจำนวนผู้เรียน อายุ ระดับสาย หรือคุณสมบัติอื่นเพื่อความเหมาะสมและความปลอดภัย

ยิมอาจปรับตารางเรียน โค้ช หรือยกเลิกคลาสเมื่อมีเหตุจำเป็น โดยจะแจ้งสมาชิกผ่านช่องทางที่เหมาะสม

7. การชำระเงิน การยกเลิก และการคืนเงิน

ค่าบริการเป็นไปตามราคาที่แสดงในระบบ ณ เวลาทำรายการ และรายการที่ต้องตรวจสอบการชำระเงินจะมีผล เมื่อยิมอนุมัติเรียบร้อยแล้ว

การคืนเงิน การพักสมาชิก (Freeze) การโอนสิทธิ หรือการขยายอายุแพ็กเกจ ให้เป็นไปตามนโยบายของแพ็กเกจ ที่ยิมประกาศ

8. พฤติกรรมและการใช้บริการ

สมาชิกต้องปฏิบัติต่อโค้ช สมาชิก และบุคลากรของยิมด้วยความเคารพ และต้องไม่กระทำการที่เป็นอันตราย คุกคาม หรือสร้างความเสียหายแก่บุคคลหรือทรัพย์สินของยิม

กรณีฝ่าฝืนกฎอย่างร้ายแรงหรือซ้ำ ยิมอาจระงับการเข้าร่วมคลาสหรือสิทธิการใช้บริการตามความเหมาะสม

9. การถ่ายภาพ วิดีโอ และเนื้อหาการสอน

ไม่อนุญาตให้ถ่ายภาพ บันทึกวิดีโอ บันทึกเสียง หรือบันทึกการสอนระหว่างคลาส โดยไม่ได้รับอนุญาตจากโค้ชหรือทางยิม

ห้ามเผยแพร่ ส่งต่อ ถ่ายทอดสด หรือโพสต์เทคนิค การสาธิต หรือเนื้อหาที่โค้ชกำลังสอนผ่าน Social Media หรือช่องทางอื่นโดยไม่ได้รับอนุญาต

หากได้รับอนุญาตให้บันทึกภาพหรือวิดีโอ สมาชิกต้องคำนึงถึงสิทธิและความเป็นส่วนตัวของบุคคลอื่น ที่ปรากฏในเนื้อหาด้วย

10. ผู้สมัครที่เป็นผู้เยาว์

สมาชิกที่เป็นผู้เยาว์อาจต้องได้รับความยินยอมจากบิดา มารดา หรือผู้ปกครองในการสมัคร การให้ข้อมูลสุขภาพ และการเข้าร่วมกิจกรรมตามที่กฎหมายหรือยิมกำหนด

11. ข้อมูลส่วนบุคคล

ยิมอาจเก็บและใช้ข้อมูลที่จำเป็นต่อการให้บริการ เช่น ข้อมูลติดต่อ ข้อมูล LINE ข้อมูลสมาชิก ประวัติการเข้าเรียน การชำระเงิน และผู้ติดต่อฉุกเฉิน เพื่อบริหารสมาชิก ติดต่อสมาชิก ตรวจสอบสิทธิและการชำระเงิน และดูแลความปลอดภัย

ยิมจะใช้และเก็บรักษาข้อมูลเท่าที่จำเป็นตามวัตถุประสงค์ และข้อกำหนดของกฎหมาย พร้อมจัดให้มีมาตรการรักษาความปลอดภัย ที่เหมาะสม

12. ข้อมูลสุขภาพ

ข้อมูลโรคประจำตัว การแพ้ยา/อาหาร หรือข้อมูลสุขภาพที่สมาชิกให้ไว้ จะใช้เพื่อความปลอดภัยในการฝึกและการช่วยเหลือกรณีฉุกเฉิน โดยระบบจะขอความยินยอมสำหรับข้อมูลสุขภาพแยกต่างหาก

13. การเปลี่ยนแปลงข้อตกลง

ยิมอาจปรับปรุงข้อตกลงเมื่อมีการเปลี่ยนแปลงบริการ ระบบ หรือข้อกำหนดที่เกี่ยวข้อง โดยจะแจ้งเวอร์ชันหรือวันที่มีผลให้สมาชิกทราบตามความเหมาะสม
